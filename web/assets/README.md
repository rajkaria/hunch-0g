# Brand assets

Hunch identity **v1.0** — masters copied verbatim from
[playhunch.xyz/brand](https://www.playhunch.xyz/brand) — plus the 0G Arena
venue variants built from the same masters.

## One module

Written lowercase, `hunch` is almost entirely arches and bowls: the same
half-circle, mirrored. Driven through the bottom edge of a hard 88 × 88 block
it becomes the mark — the gate. That gate is the whole identity, and it is what
0G Arena wears too, in the venue's own accent.

## Rules the system enforces

- **No glow, no gradient** on the mark or the logotype. Retired in v1.0 — flat
  fills, on every surface. (The violet blooms on this page are section
  lighting; nothing is applied to the artwork itself.)
- **Corners stay hard.** The only curve in the identity is the opening, even
  inside a rounded app tile.
- **Never stretch.** The module is a circle and the x-height letters are
  squares; scale both axes together.
- **Clear space** of one module radius — 17 grid units — on every side.
- **Minimum sizes:** mark 16px; logotype 96px wide in print-style placements.
  Under 20px, use the small master.
